# Modelo Supabase — v4.2

Para una instalación que ya está en v4.1.2 ejecutar únicamente `supabase/10_v4_2_alta_360_validador.sql`.

La migración agrega los campos de Alta 360 a `BBDD_VISITAS`, crea `RUTAS_LOCACION`, `BBDD_REGISTRO_VALIDADOR` y el bucket `documentos-prospecta`, migra el rol Desarrollador a Validador y actualiza RLS.
